# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-23

## Context

This project will make several technology choices early (framework, map engine, data format). Without a written record, the reasons get forgotten and decisions get re-debated.

## Decision

Record every significant architecture decision as an ADR in `docs/adr/`, using the format in `template.md`.

## Consequences

- New decisions take a few minutes to write down.
- Anyone (including future us) can see why the project looks the way it does.
- A change of direction means a new ADR that supersedes the old one, not an edit.
